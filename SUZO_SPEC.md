# SUZO LAUNCHER — ULTIMATE EDITION
Version: 1.4
Brand: SUZO
Slogan: Feel the Speed.

## Implemented in the current source
- iOS-inspired interface with Liquid Dark, Liquid Glass and Classic themes.
- Live clock and date display with configurable size and format.
- Searchable application library with page navigation.
- Four-icon dock with configurable icon count.
- Customizable grid columns, icon size, shape, labels and label size.
- Original, dark monochrome and white monochrome icon appearance.
- Compatible third-party icon-pack lookup through appfilter.xml.
- Wallpaper selection with persisted access and memory-conscious decoding.
- In-launcher quick panel linking to Android Wi-Fi, Bluetooth, display, sound and battery settings.
- Optional SUZO Keyboard input method with a basic QWERTY layout and emoji panel.
- Lightweight press and entrance animations.
- Persistent preferences and Android HOME activity integration.

## Android behavior and limits
- Minimum SDK: Android 6.0 (API 23); target SDK: Android 16 (API 36).
- A third-party launcher cannot replace the system notification shade or silently control protected system toggles on modern Android.
- The keyboard is optional and must be enabled and selected by the user in Android Settings.
- Icon packs are optional external apps and must expose a compatible appfilter.xml.
